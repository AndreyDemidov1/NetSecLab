# NetSecLab

NetSecLab — интерактивный тренажёр по анализу сетевых атак и защите. Проект разрабатывается по модульному принципу: сначала создаётся запускаемое приложение и общий слой моделей, затем по одному подключаются функциональные модули.

В этой версии подключён первый функциональный модуль — **модуль генерации атак**.

## Реализовано на текущем этапе

- Запускаемое Avalonia-приложение.
- Общий проект `NetSecLab.Core` с моделями и интерфейсами.
- Инфраструктура событий `NetSecLab.Infrastructure`.
- Отдельный модуль `NetSecLab.Modules.Attacks`.
- Генерация логических пакетов для атак:
  - SYN-flood;
  - UDP-flood;
  - ICMP-flood;
  - HTTP Slowloris.
- Настройка целевого IP, порта и интенсивности.
- Остановка генерации.
- Отображение сгенерированных логических пакетов в таблице.

На этом этапе нет модулей защиты, визуализации графиков, сценариев и отчётов. Они должны подключаться следующими ветками.

## Запуск

```bash
cd src/NetSecLab.App
dotnet restore
dotnet run
```

Или на Windows:

```bat
start.bat
```

## Структура решения

```text
src/
├─ NetSecLab.App                # Avalonia-приложение и пользовательский интерфейс
├─ NetSecLab.Core               # Общие модели, события и интерфейсы
├─ NetSecLab.Infrastructure     # Общая инфраструктура: шина событий, настройки
└─ NetSecLab.Modules.Attacks    # Первый функциональный модуль: генератор атак
```

## Принцип интеграции

Приложение не показывает пользователю технический список модулей и не требует ручного подключения. Модули интегрируются на уровне кода через:

- `ProjectReference`;
- общие интерфейсы из `NetSecLab.Core`;
- DI-контейнер;
- шину событий `IEventBus`.

Для пользователя это выглядит как единая программа, а внутри функциональность разделена на независимые части.
